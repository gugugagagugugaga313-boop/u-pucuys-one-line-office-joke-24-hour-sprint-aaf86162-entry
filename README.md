## The joke

> We took it offline, which turned out to be a second meeting about the first meeting, with worse chairs.

## How it works

`main.ts` (Node 22) writes that exact line to `/output/entry.txt`. The
output is deterministic: the same fixed text on every run, no randomness,
no network, no trailing newline. The joke is 103 characters, inside the
200-character gate.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
